# cuevik-plugins

Claude Code plugin marketplace for Cuevik delivery work.

| Plugin | What it does |
|---|---|
| `cuevik-start` | Start a project the governed way: steps 00–08, each landed by a reviewed PR |
| `cuevik-ship` | Daily loop per issue: brainstorm → requirements → backlog → intent → spec → plan → code PR |
| `cuevik-docs` | Audit and update source-of-truth docs (dependency of both) |

```text
/plugin marketplace add viralparikh-dev/cuevik-plugins
/plugin install cuevik-start@cuevik-plugins
/plugin install cuevik-ship@cuevik-plugins
```
